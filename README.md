# 🥚 Pixel Tamagotchi

Un Tamagotchi virtuel complet en pixel art, inspiré des jeux électroniques des années 90.

## 🎮 Fonctionnalités

### Système de vie complet
- ❤️ **Santé** - Soignez votre Tama quand il est malade
- 🍗 **Faim** - Nourrissez-le avec différents aliments
- 😊 **Bonheur** - Jouez avec lui pour le rendre heureux
- ⚡ **Énergie** - Laissez-le dormir pour récupérer
- ✨ **Propreté** - Nettoyez ses cacas

### Système d'évolution
- 🥚 **Oeuf** - Faites-le éclore pour commencer
- 👶 **Bébé** - Premier stade après éclosion
- 🧒 **Enfant** - Évolue après quelques minutes
- 👦 **Adolescent** - Continue à grandir
- 👤 **Adulte** - Forme finale

### 4 Mini-jeux
- 🧠 **Mémoire** - Mémorisez et reproduisez la séquence
- ⚡ **Réflexes** - Cliquez le plus vite possible
- 💃 **Dance** - Suivez le rythme avec les flèches
- 🎯 **Attrape** - Attrapez les pommes et évitez les cacas

### Animations pixel art
- Sprites dessinés à la main
- Animations de respiration
- Clignement des yeux
- Expressions (heureux, triste, mange, dort)

## 🚀 Jouer

Le jeu est disponible en ligne sur GitHub Pages :
**https://votre-username.github.io/pixel-tamagotchi/**

Ou jouez localement :
```bash
git clone https://github.com/votre-username/pixel-tamagotchi.git
cd pixel-tamagotchi
# Ouvrir index.html dans un navigateur
```

## 🎯 Comment jouer

1. **Cliquez sur "Faire éclore"** pour commencer
2. **Surveillez les statistiques** en haut de l'écran
3. **Utilisez les boutons** pour interagir :
   - 🍗 **Manger** - Choisissez parmi 5 aliments
   - 🎮 **Jouer** - 4 mini-jeux disponibles
   - 😴 **Dormir** - Le Tama récupère de l'énergie
   - 🧹 **Nettoyer** - Supprime les cacas
   - 💊 **Soigner** - Quand il est malade
   - 📊 **Stats** - Voir les statistiques détaillées

4. **Laissez-le évoluer** - Il change de forme avec le temps !

## 💾 Sauvegarde

Le jeu sauvegarde automatiquement dans le **localStorage** du navigateur. Votre Tama sera là quand vous reviendrez !
